# Richa model provenance

## Companion
- Target format: GLB/glTF 2.0.
- Candidate: Kaoruko Waguri by nezunyann on Sketchfab.
- Source page: https://sketchfab.com/3d-models/kaoruko-waguri-a8b4d140c11446f78e947bf45290ae2d
- Reported source license: CC Attribution-NonCommercial-ShareAlike.
- The model file is NOT committed to this repository. Install/import only a copy you are permitted to use.

## Offline voice
- Engine: Kokoro-82M via kokoro-android.
- Android dependency: dev.ffmpegkit-maintained:kokoro-android:0.1.0.
- Model source: https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX
- Selected setup model: model_q8f16.onnx (~86 MB).
- SHA-256: 04c658aec1b6008857c2ad10f8c589d4180d0ec427e7e6118ceb487e215c3cd0
- Voice: af_heart (female English voice supplied by the Android runtime).
- Inference is local after the one-time model installation.

## Important
Personal use does not automatically override a model's license. Richa therefore stores the Waguri asset outside Git and records the source instead of redistributing it.
